# laravel-vue-saas-starter
A Laravel 11 + Vue 3 SaaS starter kit with role-based auth, a dashboard shell, and a CRUD module — built as a reusable foundation for SaaS projects.

## Stack
- Laravel 11
- Vue 3 (Composition API) + Inertia.js
- Laravel Breeze (Vue stack)
- Vite + Tailwind CSS

## Development
```bash
php artisan serve
npm run dev
```
